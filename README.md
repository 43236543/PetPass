# PetPass — система учёта домашних питомцев

## 1. Описание проекта

PetPass — клиент-серверное веб-приложение для учёта домашних питомцев и хранения информации об их ветеринарных процедурах.

Приложение позволяет пользователям регистрироваться, входить в аккаунт, добавлять питомцев, вести историю ветеринарных записей и просматривать статистику.

## 2. Используемые технологии

- Python
- FastAPI
- SQLAlchemy 2.x
- SQLite
- Alembic
- Pydantic
- HTML, CSS, JavaScript
- Fetch API
- Git

## 3. Основные возможности

- Регистрация и авторизация пользователей.
- Хранение данных пользователей и их питомцев.
- Добавление, просмотр, редактирование и удаление питомцев.
- Создание и просмотр ветеринарных записей.
- Использование справочника типов процедур.
- Поиск, фильтрация, сортировка и пагинация питомцев.
- Просмотр статистики.
- Получение ближайших напоминаний.
- Разграничение доступа к данным разных пользователей.

## 4. Структура базы данных

В проекте используются четыре основные таблицы:

- **users** — данные пользователей;
- **pets** — информация о питомцах;
- **record_types** — справочник типов ветеринарных процедур;
- **vet_records** — ветеринарные записи питомцев.

Связи между таблицами:
- Один пользователь может иметь нескольких питомцев.
- У одного питомца может быть несколько ветеринарных записей.
- Один тип процедуры может использоваться во многих ветеринарных записях.

## 5. Установка и запуск

### Требования

Для запуска необходимы:
- Python 3.10 или новее;
- pip;
- Git.

### Клонирование проекта

```bash
git clone <ссылка-на-репозиторий>
cd PetPass
```

### Создание виртуального окружения

Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### Установка зависимостей

```powershell
pip install -r requirements.txt
```

### Настройка переменных окружения

В корневой папке проекта создайте файл `.env` и добавьте секретный ключ:

```env
SECRET_KEY=your-long-random-secret-key
```

Для рабочего запуска используйте собственный случайный секретный ключ. Не публикуйте файл `.env`.

### Применение миграций базы данных

```powershell
alembic upgrade head
```

### Заполнение справочника типов процедур

```powershell
python -m app.seed
```

### Запуск приложения

```powershell
uvicorn app.main:app --reload
```

После запуска приложение доступно по адресу:

http://127.0.0.1:8000

Документация API Swagger:

http://127.0.0.1:8000/docs

## 6. Безопасность

- Пароли пользователей хранятся в виде хешей.
- Для авторизации используются серверные сессии.
- Доступ к API без авторизации ограничен.
- Пользователь может работать только со своими питомцами и ветеринарными записями.
- Для защиты от доступа к чужим данным используются проверки владельца записи.

## 7. Авторизация

Для работы с приложением необходимо зарегистрировать пользователя или войти в существующий аккаунт.

После авторизации пользователь получает доступ к своим питомцам, ветеринарным записям и статистике.
